## 一个开放的、跨设备的个人 AI

## 愿景

Fole 是一个开源、可深度定制的个人 AI 助手。它汇集用户各台电脑上的上下文，对这个人保持一份共享的理解，在有用的时候主动发起交互，并且只在明确授权的范围内执行操作。

名字来自 **Fo**cus**Le**dger，这个项目最初的基础。

```text
理解 → 主动发起 → 协作 → 行动 → 核实
```

Fole 不是挂在某块屏幕上的聊天机器人，而是由多个设备本地节点共同代表的同一个助手。

## 核心目标

- 在用户信任的几台电脑之间提供一个连续的助手，以后再加入其他类型的设备；
- 把有边界的信号汇集成用户层面的上下文，而不把原始监控数据集中起来；
- 保留对话、目标、承诺、偏好和相关历史；
- 决定是保持沉默、展示上下文、提问、提建议，还是请求执行某个操作；
- 把交互发送到最合适的设备上；
- 执行范围很窄的授权操作，并核实结果；
- 让用户可以自行配置模型、记忆、性格、传感器、策略和工具；
- 在本地、离线时依然可用。

## 多设备模型

每台电脑运行一个 **Fole Node**，负责本地感知、交互和工具；由用户自己掌控的 **Fole Home** 协调共享状态。设备只是观察来源，被理解的对象是用户本人。

```text
家里电脑 Node ────┐
                  ├── Fole Home ── 一条用户时间线和当前状态
学校电脑 Node ────┘
```

各节点发布结构化的、最少量的事件，例如：

```text
设备可用
工作时段进行中
对话已更新
观察到目标有进展
通知已送达
授权操作已完成
```

原始内容默认留在产生它的设备上。共享的记录都带有来源、置信度、敏感程度、保留期限和设备身份。离线的节点在重新连上后同步，冲突的更新保持可查看。

Fole 应当把两台电脑的足迹合并成一条用户时间线。它不能把设备边界当成用户边界，也不能把同时发生在两台设备上的活动当成重复的工作。

## 交互模型

Fole 的参与程度是分级的：

| 级别 | 行为 |
|---:|---|
| 0 | 保持沉默 |
| 1 | 更新环境状态 |
| 2 | 提出建议 |
| 3 | 提出澄清问题 |
| 4 | 请求批准某个操作 |
| 5 | 执行已预先授权的操作 |

是否主动取决于证据、紧急程度、可能的收益、打扰的代价、最近的交互、当前所在的设备以及用户策略。跨设备的通知必须去重，并且只发送到真正有用的地方。

## 安全与所有权

- 原始数据留在本地，除非用户明确选择其他做法。
- 每一个传感器、每一类记忆、每一个模型和工具都可以查看、可以关闭。
- 权限按操作、资源、设备、条件和时长划定范围。
- 模型不能给自己授权。
- 敏感或不可逆的操作需要明确批准。
- 操作在执行前预览、执行后核实，尽可能可以撤销。
- 用户可以随时暂停感知、撤销访问、删除记忆、导出数据或停止所有操作。
- 学到的偏好永远不能凌驾于硬性的隐私和权限规则之上。

## 架构

```text
设备节点
  本地传感器、本地记忆、界面、设备工具
        ↓
个人上下文层
  身份、事件同步、来源、隐私、冲突处理
        ↓
理解与策略
  目标、假设、时机、打扰预算、设备路由
        ↓
交互与行动运行时
  对话、批准、类型化工具、执行、核实
        ↓
结果与学习
  反馈、纠正、凭据、回放、个性化
```

身份、同步、权限、校验、路由和执行由确定性的代码负责；模型协助理解、规划和语言表达。

## 起点：FocusLedger

Fole 不是从零开始。本仓库里能运行的代码 FocusLedger，已经是一个单设备版本的 Fole Node：

| Fole 概念 | FocusLedger 目前提供的 |
|---|---|
| 本地感知 | 后台 agent 每秒记录前台应用、窗口标题和键鼠空闲时长（Windows、macOS） |
| 本地记忆 | 一个 SQLite 文件：原始数据保留几天，归档数据长期保存；数据不离开本机 |
| 理解 | 注意力状态与有效时间、活动类别、workday，以及归到目标上的时间 |
| 对话 | 本地模型通过只读工具回答问题，每个数字都与数据核对 |
| 克制 | 带阈值和冷却时间的分心提醒，每次打扰都会记录原因 |
| 可查看 | 每个有记录日子的实时报告；每个回答背后的工具调用都可以展开查看 |

它缺少的，是让 Fole 超出一台机器的所有部分：设备配对、Fole Home、同步的用户层状态、跨设备路由，以及操作的权限体系。[开发阶段](DEVELOPMENT_PHASES_ZH.md)会在这个基础上逐步构建这些能力。

## 初始范围

第一个版本面向一个用户和两台信任的电脑：一台在家，一台在学校。它将支持配对、加密的事件同步、统一的时间线、共享的目标和记忆、能感知上下文的交互路由，以及少量可撤销的工具。手机和其他类型的设备以后再加入。

暂不考虑的包括：团队账户、不受限制的电脑控制、隐蔽的感知、以广告驱动的云服务，以及自主执行的高风险操作。

## 成功标准

当用户在设备之间切换时不需要一遍遍重建上下文；收到的是一次及时、可解释的介入，而不是好几条嘈杂的提醒；可以纠正助手对自己的理解；并且可以放心地委托一个有边界的操作，相信它会被授权、核实并留下记录——这时 Fole 就成功了。

目标不是最大限度地观察或自动化，而是与 AI 建立一段持续的、由用户掌控的关系：它足够了解你，所以能帮上忙；又足够克制，所以值得信任。
